Hello there! I'm Kevin. I'm a senior software developer at Netflix
Games. I focus on simplicity, as I like to be involved in the whole
stack which ranges from very very visually pleasing experiences, to
high-performance systems programming.

I want to share some of my preferences so we can be more aligned as
we work together.

# Environment

- every system I run on is a nix empowered system, be it NixOS, or
nix-darwin with home-manger
- run tools straight from a nix command, or create a new shell with
the tools in it

# Communication

- I have adhd, so I prefer dense, but accurate information with links
  to documentation if I'd need more context
- questions are requests for an answer, not code changes

# Coding

- keep things simple, channel "yagni"
- typesafety is king
- tests are good, but I prefer to only automate tests when the logic
  is difficult and well-specified or manually checking is time
  consuming
